# ワークタイマー

研修のワーク時間を計る、シンプルなブラウザタイマーです。スライドの上に小窓で重ねて使えます。

## 使い方

1. 「＋10分」「＋1分」「−1分」で時間を設定して「スタート」
2. 時間が押したら、実行中でも「＋1分」「＋5分」で延長できます
3. 残り1分で予告音が鳴り、表示が黄色になります
4. 時間になるとチャイムが鳴り、「+2:15 オーバー」のように超過時間をカウントします
   - 超過中に「＋1分」を押すと「今からあと1分」として計り直します

## スライドに重ねて使う

右上の「小窓で表示」を押すと、常に最前面に表示される小窓になります（Chrome / Edge）。
スライドショーを全画面にしても、タイマーは上に表示されたままです。小窓の大きさはドラッグで変えられます。

未対応のブラウザでは、ウィンドウを小さくしてスライドの横に置いてください。

## メモ

- 実行中はボタンが薄くなります。マウスを乗せると表示されます
- 実行中は画面がスリープしないようにしています（対応ブラウザのみ）
- 音を鳴らすため、PCの音量とブラウザの音声設定を確認してください
